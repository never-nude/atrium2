# Preview — Atrium (Night Atrium build)

Full Astro project. Run it locally:

    npm install
    npm run dev          # http://localhost:4321

Open a piece that has a 3D model and click **Examine in 3D** to orbit, change
brightness / finish, and toggle wireframe. Good ones to try:

    /works/michelangelo/david/
    /works/laocoon/
    /works/rodin/the-thinker/
    /works/venus-de-milo/

Other entry points:

    /            home
    /museum/     browse + filters (Era / Place / Material / Maker / Media)

Prefer the production build?  `npm run build && npm run preview`

12 works have 3D today: michelangelo/david, michelangelo/moses, michelangelo/bacchus,
rodin/the-thinker, laocoon, venus-de-milo, capitoline-venus, discobolus,
apollo-belvedere, dying-gaul, germanicus, athena-lemnia. The rest are photo-only.
